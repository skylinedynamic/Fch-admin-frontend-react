# Calendly v2 (partner portal): central app, own Calendly for everyone, several attendees

**Date:** 2026-11-22
**Branch:** `feature/calendly-v2` (from `stage`)
**Backend:** `fch-api/docs/handoff/2026-11-22-calendly-v2.md` (API shapes, rules, setup)
**Replaces:** the 2026-11-10 / 11-16 / 11-18 Calendly work (removed and rebuilt).

## Problem
- Partners kept their own Calendly app keys (Settings › Calendly and Partners › Configuration); staff shared the partner's connection and could not connect their own.
- An appointment could be with only one person; no outside email.

## Solution
- Old Calendly code removed: `components/Calendly/*`, `modules/calendly/*`, `pages/settings/components/CalendlySettings.tsx`, their tests and e2e spec. `AppointmentModal.jsx`, `Appointments.jsx`, their tests and `modules/appointment/types.ts` went back to their pre-Calendly versions (commit `4844ee4a`, despite its title, was Calendly-only). Partner configuration, `SettingsForm`, `settingsSections` and `queryKeys` had unrelated changes too, so only their Calendly parts were taken out.
- **Settings › Calendly Configuration** (`/settings/calendly-configuration`): host only, permission `update calendly configuration settings` (`config/calendlyConfiguration.ts`). Client ID + write-only Client Secret, the redirect URI and scopes to enter on the Calendly app (`CalendlyConfigurationForm.tsx`). Partners › Configuration no longer has a Calendly section.
- `modules/calendly/` — same as the borrower portal plus `useCalendlySettings` / `useSaveCalendlySettings`.
- `components/Appointment/` — `CalendlyConnectionCard`, `AttendeePicker`, `CalendlyBookingFields`, `AddToCalendly` (same as the borrower portal; a picked user keeps their name when the "Meeting with partner" list changes).
- `AppointmentModal.jsx` — attendee picker instead of the single "Appointment With"; availability check and the re-check on Save send attendees, and only `creator_conflicts` blocks; an invitee (now any user attendee) still only moves the time; a Calendly meeting's people and time are not sent; view shows everyone, Calendly badge, Join, Reschedule, Add to Calendly; debug `console.log`s removed.
- `Appointments.jsx` — Calendly card for every user, badge and links on the list, Calendly meetings not draggable.
